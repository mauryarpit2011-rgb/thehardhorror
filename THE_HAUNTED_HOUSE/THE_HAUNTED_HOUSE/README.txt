THE HAUNTED HOUSE
================
A browser-based 3D horror prototype.

CONTROLS
WASD = move
Mouse = look
E = interact
F = flashlight

PLAY LOCALLY
Open index.html in a modern browser while connected to the internet (the game loads Three.js from a CDN).

FREE DEPLOYMENT
1. GitHub Pages: create a repository, upload index.html, then Settings > Pages > Deploy from branch.
2. Cloudflare Pages: create a Pages project and upload/deploy the folder.
3. Netlify: drag the folder into Netlify Drop.

NOTE
This is a lightweight browser prototype. For truly AAA-quality visuals, custom 3D models, animations, textures and audio should be added later.
